# Forge

Forge is an open source tool that lets you deploy source straight into Kubernetes, whether it's for development, testing, or production. Forge supports dependency management, fast parallel builds, and more. Forge is self-contained, and designed to run anywhere from your laptop to your CI system.

## Requirements

- Python 3.8 or higher
- Kubernetes cluster access
- Docker

## Installation

```bash
pip install -r requirements.txt
```

## Upgrade Notice

This project has been updated to Python 3.8+ with modern dependencies. If you're upgrading from an older version, please see [UPGRADE_GUIDE.md](UPGRADE_GUIDE.md) for details on breaking changes and migration steps.

For more information on how to use Forge, visit https://forge.sh.
